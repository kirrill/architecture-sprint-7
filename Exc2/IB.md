# Задание 2
## Выбор разделов для включения в проверочный лист
Исходя из проблем и потребностей бизнеса, а именно: 
1. Нарушение контроля данных (Несколько точек регистрации клиентов, нет ограничений на доступ к данным со стороны систем обработки данных)
2. Проблемы с API партнеров (Нет контроля за передаваемыми данными, передаются персональные данные, нарушен контроль доступа)
3. Искажение персональных данных клиентов
4. Управление и хранение потоков данных
5. Предотвращение утечек
6. Соответствие требованиям законодательства

В проверочный лист следует включить все разделы:
- I. **Управление доступом** - для решения проблем 1,2,5,6. 
*Т.к. контроль доступа это важнейший аспект, который отвечает за то, кто и на каких условиях может получить доступ к данным.*
- II. **Безопасность данных** - для решения проблем 3,4,5,6. 
*Т.к. этот  раздел отвечает за методы защиты данных, их классификацию и шифрование.*
- III. **Защита инфраструктуры** - для решения проблем 1,2,5,6. 
*Т.к. защита инфраструктуры это безопасность сетевой инфраструктуры, серверов, рабочих станций и облачных ресурсов.*
- IV. **Управление инцидентами** - для решения проблем 3,4,5,6. 
*Т.к. этот раздел отвечает за оценку способности организации оперативно выявлять инциденты безопасности и реагировать на них.*
- V. **Специфические аспекты** - 
*Чтобы убедиться, что особенности инфраструктуры компании не могут стать причиной проблем ИБ.*
    - V.1. **Общие вопросы** - для решения проблем 1,5,6. 
    *Т.к. следует убедиться, что сотрудники используют защищенные и контролируемые устройства для доступа к корп. ресурсам*
    - V.2. **Управление оборудованием и физической безопасностью** - для решения проблем 5,6. 
    *Т.к. важен и физический контроль за доступом к серверам.*
